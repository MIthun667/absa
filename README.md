# DimABSA Track A Multi-Task Learning

Research repository for studying multi-task learning across Track A of
SemEval-2026 Task 3: Dimensional Aspect-Based Sentiment Analysis (DimABSA).

## Track A

- Subtask 1: Dimensional Aspect Sentiment Regression (DimASR)
- Subtask 2: Dimensional Aspect Sentiment Triplet Extraction (DimASTE)
- Subtask 3: Dimensional Aspect Sentiment Quadruple Prediction (DimASQP)

## Research Process

1. Dataset forensic audit
2. Single-task baselines
3. Naive multi-task baseline
4. Negative-transfer analysis
5. Hypothesis formulation
6. Proposed multi-task framework
7. Ablation and robustness experiments

No proposed architecture is assumed before the empirical diagnostic stages.
